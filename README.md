## 这是个什么游戏？

你扮演一名刚拿到 CCNA 的专科毕业生，从三线城市的小网工开始，处理真实的网络工单，在每一个选择里学技术、攒经验、升职加薪。

游戏里没有「重启试试」这种答案——所有选项都是技术上听起来合理、但各有各的坑，你得真正理解问题才能选对。

## 游戏特色

- **真实工单场景** — 广播风暴、MTU 黑洞、VPN 并发、Docker 网段冲突……都是行业里真实发生过的故障
- **考证副本** — 第二章内置 11 道路由交换真题，5 种题型（单选/多选/判断/填空/拖拽），答对 8 题获得网络系认证
- **职级成长体系** — 从初级网工 ¥3500 到 CTO ¥25000，拿 CTO 需要准确率 ≥90% + 声誉 ≥60，不是随便打打就能到的
- **便利店系统** — 用游戏内现金买咖啡补精力、约兄弟撸串恢复状态、加班充电换 XP
- **分享图片** — 结局生成战绩卡片，二维码让朋友扫码来挑战

## 技术栈

纯原生 HTML + CSS + JavaScript，无框架，无依赖，单文件可独立运行。

```
router-game/
├── index.html      # 章节选择主页
├── chapter1.html   # 第一章
├── chapter2.html   # 第二章
└── template.html   # 章节开发模板（新章节从这里开始）
```

## 参与共创

这个游戏由**鸿鹄论坛**社区共同打造，欢迎网工朋友参与：

**💬 方式一：反馈和建议**
- 游戏内「留言 / 报告 Bug」按钮
- 鸿鹄论坛讨论帖：[点击进入](https://bbs.hh010.com/forum.php?mod=viewthread&tid=675592)

**✍️ 方式二：贡献剧情**

仓库里有 `template.html`，注释写得很详细，按格式填内容就行：

```javascript
// 工程师只需要填这里
const SCENARIOS = [
  {
    id: 'c3s1',
    chapter: '第一关：你的故事',
    ticket: { title: '工单标题', ... },
    dialogue: '人物说的话',
    choices: [
      { text: '选项', result: 'good', body: '结果描述', learn: '技术知识点' },
      // ...
    ]
  }
];
```

欢迎 Pull Request，也欢迎直接在论坛发你写的场景剧情。
